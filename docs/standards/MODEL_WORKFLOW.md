# 开发协作与独立复核

这是公开源码副本的协作约定。个人模型配置、内部比较报告、会话编号和历史协调记录不随仓库发布。业务规则优先查 [V2 脱敏文本](../specs/V2.0-文件索引.md)，当前源码范围见 [交接](../../HANDOFF.md)。

## 任务边界

以用户当前授权为准，需求蓝图、旧待办和历史验收记录不自动成为新任务。开始前读取工程规范和复用索引，检查工作区并保护未提交修改；按需要查源码、调用方与回归测试。

## 独立复核

涉及权限、敏感数据、数据库迁移、恢复、价格和对外承诺的改动，使用具备相应能力的审查者进行独立核验。代码、输入材料和版本须固定；同一文件与测试数据库避免多个执行者同时写入。模型输出和历史通过标签不能替代实际证据。

交付背景仅包含任务必需的已核验事实、待验证假设、当前代码和合成样例。不得加入凭据、完整客户资料、原始私人会话或整库。工具或模型存在限制时如实记录。

## 验证与交接

复用现有 CI、治理检查及固定测试。业务 AI 的技能、提示词和模型变更遵守 A08/A09 的回归、审批、发布和回滚要求；离线代码检查不代表真实模型评测或上线通过。

交接记录改动范围、复用路径、测试命令与本轮结果、未验证项和限制。后续同步公开仓库前重新执行脱敏检查，不能从原开发项目直接推送历史或运行资料。
