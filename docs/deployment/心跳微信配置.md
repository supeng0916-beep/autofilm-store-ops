# 可选通知渠道

作品集默认关闭定时通知，演示 Agent 对话、草稿与任务控制台不要求连接外部消息渠道。

`WG_HEARTBEAT=off` 与 `WG_INDUSTRY_DAILY=off` 保持关闭；`WG_HEARTBEAT_WEIXIN_TO` 不填写真实收件人。网关模板中的渠道条目仅为配置参考，不证明插件已安装、账号已登录或具备发送授权。

如需接入自己的消息渠道，应按实际网关及插件版本配置，单独核对收件人、授权和停止开关。不要将渠道凭据、收件人标识或真实消息记录提交到仓库。

参见 [后端配置模板](../../backend/.env.example) 与 [OpenClaw 接入](../../openclaw/README.md)。
