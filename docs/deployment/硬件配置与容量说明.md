# 演示环境容量核验说明

本作品集不提供未经原始日志支持的性能结论。旧部署文档中的设备数据、并发结果与容量推算不作为本版成果指标。

如需补充可公开性能数据，请在独立演示环境记录：代码提交、设备与软件版本、数据集规模、命令、并发定义、采样方法、完整原始输出和异常情况。Web 请求测试、数据库负载、模型响应时间与多任务隔离应分别测量。

存储需求取决于图片、视频、数据库和备份保留方式；不能仅从软件目录大小推断长期容量。结果应注明测试环境与适用范围，不作生产容量承诺。

运行入口见 [启动指南](../GETTING_STARTED.md)，当前已执行检查见 [验证记录](../VALIDATION.md)。
