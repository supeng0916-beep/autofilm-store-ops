# 密钥替换说明（网盘交付包必读）

> 出于安全，本包**不含正式 AI 密钥**：`openclaw/config/.env` 里是占位值（change-me）。
> 正式密钥由技术支持通过**单独渠道**（短信/电话）发送，收到后按下面任一种方式替换。
> 替换完成前：系统所有业务功能（客资/预约/施工/审批/复盘）正常使用，仅 AI 相关功能提示「暂不可用」——这是正常现象，不是故障。

## 方式一（推荐）：双击「换密钥.command」

1. 在 `autofilm-store-ops` 文件夹里双击「**换密钥.command**」；
2. 按提示粘贴新 APIKey（输入时不显示字符，回车确认）；
3. 脚本会把新密钥同步写入 `openclaw/config/.env` 与 `app/backend/.env`，并自动轮换网关 token（两处保持同值，防漏改）；
4. 双击「**重启.command**」，AI 恢复。

## 方式二：手工改两个文件

用「文本编辑」打开下面两个文件（打开方式选普通文本），替换对应等号后面的值：

**文件 1：`autofilm-store-ops/openclaw/config/.env`**

```
WG_OPENCLAW_PRIMARY_KEY=←粘贴新 APIKey
WG_OPENCLAW_GATEWAY_TOKEN=←自定义一串新 token（如 48 位随机字符）
WG_MCP_TOKEN=←自定义一串新令牌（≥16 字符；AI 深查工具专用——手改文件时两处必须同值，缺这行 AI 助手查不到排期/工单/知识）
```

**文件 2：`autofilm-store-ops/app/backend/.env`**（若已启动过系统才有此文件）

```
WG_OPENCLAW_GATEWAY_TOKEN=←与文件 1 的 token 完全相同
WG_EMBEDDING_API_KEY=←与文件 1 的 APIKey 完全相同
WG_MCP_TOKEN=←与文件 1 的 MCP 令牌完全相同
```

保存后双击「重启.command」。

## 注意事项

- 两个文件的 `WG_OPENCLAW_GATEWAY_TOKEN` **必须完全一致**，否则后端连不上 AI 网关；
- 密钥等同现金：只存本机这两个文件，不发微信/网盘/截图；
- 换完密钥后，旧密钥请联系技术支持作废；
- 任何时候重跑「换密钥.command」即可再次更换。
