# 部署脚本参考

本目录保留本机打包、启动、备份和恢复脚本，供阅读工程实现。招聘演示使用 [独立开发环境启动指南](../docs/GETTING_STARTED.md)，不使用真实业务运行包。

| 入口 | 用途 |
| --- | --- |
| package.sh | 生成本机运行包 |
| 启动.command / 停止.command / 重启.command | 管理本机应用进程 |
| backup.sh / restore.sh | 数据库与上传目录的备份恢复参考 |
| 守护安装.command / ops/watchdog.sh | 本机进程守护参考 |

这些脚本可能安装依赖、创建或迁移数据库、复制环境文件及上传目录。执行前阅读脚本并指定独立演示环境。本轮没有执行生产部署、恢复演练或对外通知。

账号由部署者通过现有角色配置创建，作品集不包含员工名册。真实环境变量、模型令牌、数据库文件和业务素材均不随源码分发。运行包可能包含本机配置，因此不应作为公开附件。

AI 接入见 [OpenClaw 说明](../openclaw/README.md)。可用性与费用取决于实际模型和配置，不能把安装脚本或占位模板当作已经完成集成验收。
