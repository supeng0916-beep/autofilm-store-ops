# skill-inspiration-scan（灵感周期扫描 · 手动版）

定期给灵感库**找新货**：搜近一周公开的「贴膜/汽车后市场」爆款分析文章，
把文章里被分析的爆款提炼成候选参考。输出为候选预览数组，仅返回给前端，
由人挑选确认后才逐条录入灵感库（本技能不写库）。

## 输入

`message` 是 JSON 字符串：

```json
{
  "taskId": "…",
  "taskType": "marketing.inspiration_scan",
  "context": {
    "date": "2026-09-07",
    "instruction": "按技能流程：……"
  },
  "constraints": { "boundary": "…" }
}
```

## 工作流程（严格按顺序执行）

### 第一步：联网搜索（web_search，最多 4 次）

- 搜索方向（视预算取舍，关键词可自行细化、可带「近一周/最新」限定）：
  1. 汽车贴膜赛道的爆款视频分析（如「汽车贴膜 爆款视频」「贴膜 短视频 火了」）
  2. 汽车后市场/汽服门店的热门内容玩法（热门账号、热门形式的分析文章）
  3. 平台侧汽车内容趋势（抖音/视频号 汽车内容 热门/趋势）
- **搜索失败或无结果**：如实记录，一条候选都不编

### 第二步：提炼候选（思考在内部完成，不输出过程）

- 提炼对象是**文章里被分析的爆款视频**，不是文章本身；一篇文章最多提炼它
  分析得最透的 1~2 条
- 每条候选必须能在原文找到依据：钩子怎么开的头、内容怎么组织、
  文章披露了什么互动数据——原文没有的字段留 null，不脑补
- 找不满 3 条就如实少给；一条都没有则 items 为空数组，在 scanNote 说明

## 输出纪律（最高优先级）

- 全文简体中文；思考过程一律内部完成，**最终回复必须且只能是一个 JSON 对象**，
  不得用 Markdown 代码块包裹、不得附带解释文字
- `sourceUrl` 必须是本次搜索结果里的真实链接；`metrics` 只写文章披露的数据
  （如「50w 赞」），没有则 null，**禁止编造或加码互动数据**
- 搜到的是别人家内容：提炼**参考方向**（钩子手法/结构组织），不照抄文案
- `tags` 用短词、对齐内容支柱口径（产品科普/施工过程/客户案例/避坑/热点借势等），≤6 个

## 输出（严格 JSON，无其他文本）

```json
{
  "items": [
    {
      "platform": "抖音",
      "title": "被分析的爆款视频标题或概括（≤50 字）",
      "hookText": "其开头钩子的拆解：手法+方向",
      "structure": "内容结构：分段式描述",
      "rhythm": "节奏卡点；文章没讲为 null",
      "metrics": "文章披露的互动数据；没有为 null",
      "tags": ["施工过程", "避坑"],
      "sourceUrl": "来源文章链接（本次搜索真实结果）"
    }
  ],
  "scanNote": "本次扫描整体说明：搜到什么/哪些因不相关被弃用；空结果时说明原因"
}
```

字段名用英文、按模板拼写；items 数组 0~5 项。
