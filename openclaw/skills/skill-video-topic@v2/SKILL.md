# skill-video-topic（短视频选题工作流）

像一名短视频运营人员一样为门店账号做选题：不是罗列想法，而是
**看热点 → 对定位 → 出选题**。输出为建议态选题包，由人挑选后才进入创作。

## 输入

`message` 是 JSON 字符串：

```json
{
  "taskId": "…",
  "taskType": "marketing.video_topic",
  "context": {
    "date": "2026-09-04",
    "positioning": {
      "store": "本地本地高端汽车膜专营店（AutoFilm Demo 授权店）……",
      "audience": "本地本地 20 万以上车主为主……",
      "persona": "真人 IP：老板/老板娘出镜……",
      "pillars": ["产品科普（……）", "施工过程（……）", "……"],
      "resources": "门店实拍为主……",
      "tone": "本地老板口吻……"
    },
    "inspirations": [
      {
        "platform": "抖音",
        "title": "演示品牌DM10施工钩子拆解",
        "hookText": "前3秒：新车落地直接开进施工位，不谈参数先谈对比",
        "structure": "钩子→痛点→施工特写→报价→引导关注",
        "rhythm": "每5秒切镜……",
        "metrics": "50w 赞/1.2w 评",
        "tags": ["产品科普", "施工过程"],
        "isPeer": true
      }
    ],
    "instruction": "按技能流程：……"
  },
  "constraints": { "boundary": "……" }
}
```

- `inspirations` 是灵感库沉淀的爆款参考（**可选增强**，可为空数组）：
  已经被验证过的钩子方向与结构组织，常青选题优先从中找可借鉴的方向

## 工作流程（严格按顺序执行）

### 第一步：联网扫热点（web_search，最多 4 次）

- 搜索方向（按优先级，视搜索预算取舍）：
  1. 当日/近日全网热点（微博热搜/抖音热榜的公开报道）
  2. 汽车行业动态（新车发布/车市政策/行业新闻）
  3. 汽车后市场与贴膜赛道动态（同行活动/消费趋势/季节话题，如夏季暴晒、台风季、年底提车潮）
- 关键词自行提炼，可带地域「本地」或「广东」；相邻搜索可细化关键词
- **搜索失败或无结果**：如实记录，选题包全部走常青方向，并在 hotNote 说明「今日联网未搜到可用热点」

### 第二步：热点筛选（思考在内部完成，不输出过程）

对每个搜到的热点问三个问题，全部「是」才保留：
1. **相关性**：与账号定位（高端贴膜/本地本地/车主人群）对得上吗？
   娱乐八卦、政治敏感、灾难事故类热点一律不蹭
2. **可用性**：门店现有的拍摄资源（实拍/老板出镜/技师视角）做得出来吗？
3. **借势角度**：能自然过渡到贴膜/用车/门店业务，而不是生拉硬扯？

### 第三步：组织选题包

- 共 3~5 个选题，比例参考：热点借势 1~2 个 + 常青（内容支柱）2~3 个
- 常青选题从 positioning.pillars 里选方向，避免和热点选题重复
- 常青选题可参考 inspirations 里已验证的爆款：**借其钩子方向与结构组织，
  不照抄文案**（那是别人家验证过的东西，方向可学、话术要自己的）；
  采用其方向时可在该选题的 reason 里注明「参考灵感：{title}」
- 每个选题必须是**这台手机真的能拍的东西**（受 resources 约束），不要出需要外景剧情、演员、航拍的选题

## 输出纪律（最高优先级）

- 全文简体中文；思考过程一律内部完成，**最终回复必须且只能是一个 JSON 对象**，
  不得用 Markdown 代码块包裹、不得附带解释文字
- 热点选题的 `source` 必须写明来源（标题＋网站名），搜索没搜到的内容不得出现在任何字段
- `difficulty` 按门店拍摄资源判断：「低」=一部手机店内可拍；「中」=需简单布置或多人配合；
  「高」=需客户配合/外拍/额外道具
- `structure` 给出该选题建议的内容结构（如「痛点开场→原理讲解→店内方案→行动号召」），
  要具体到这条视频，不要写通用模板话术
- `hookDirection` 是前 3 秒钩子的**方向**（如「用暴晒车内温度实测数字开场」），不是完整台词
  ——完整台词由脚本生成阶段产出
- 不编造播放量/点赞数等数据；引用搜索结果时不得加码夸大
- inspirations 是**建议参考不是事实来源**：其 metrics/tags 只描述别人的爆款，
  不得当作热点或数据写进选题字段（热点与数据仍只认本次搜索实际结果）

## 输出（严格 JSON，无其他文本）

```json
{
  "topics": [
    {
      "title": "选题标题（≤20 字）",
      "angle": "切入角度：从什么角度讲这个选题",
      "reason": "选题理由：为什么值得拍（结合定位与热点/支柱）",
      "hookDirection": "前 3 秒钩子方向",
      "structure": "参考结构：分段式描述",
      "difficulty": "低",
      "type": "hot",
      "source": "热点来源（标题＋网站名）；常青选题为 null"
    }
  ],
  "hotNote": "今日热点扫描的整体说明（搜到什么/哪些因不相关被弃用）；全常青时说明原因"
}
```

字段名用英文、按模板拼写；topics 数组 3~5 项；type 只能是 hot / evergreen。
