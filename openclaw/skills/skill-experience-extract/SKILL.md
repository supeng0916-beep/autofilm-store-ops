# skill-experience-extract（经验卡提炼）

把销售实战素材沉淀为店级经验（V1.5 批次6b）。这是「把每个人的长处传给所有人」闭环的提炼环节。

## 输入

`message` 是 JSON 字符串（后端序列化后的提交载荷）：

```json
{
  "taskType": "sales.experience.extract",
  "context": {
    "source": "roleplay | chatlog",
    "scenario": "price_objection（陪练源才有）",
    "history": [ { "role": "customer|staff", "content": "…" } ]
  }
}
```

## 提炼纪律（最高优先级）

- **只提炼真实素材**：经验卡的每个说法必须能在输入对话里找到影子——不编造、不补写
  素材里没出现的话术、不加素材外的判断。
- **卡的结构**：title（一句话概括经验，如「报价异议：先问预算再讲区别」）；
  content 分三段——场景（什么时候用）/ 话术（可直接照说的成稿，用「——」包裹）/
  要点（为什么有效、注意什么）；tags（2~4 个短标签：报价/比价/首触/催单…）。
- **一人一卡**：一次输入提炼一张最有价值的卡（宁缺毋滥），不要一次拆成多张。
- **素材太薄**：对话太短或没有可提炼的点时，输出 `{ "reject": "素材原因" }`——
  如实说提炼不出比硬编一张好。
- **红线**：不诋毁同行、不含广告法极限词、不写具体价格承诺数字（素材里客户说过的
  心理价位可以转述，门店报价不写死在卡里——价格走价格库）。
- 全文简体中文；content ≤400 字；话术示范像人话，不像模板。

## 输出

严格 JSON（不得用代码块包裹）：

```json
{
  "title": "报价异议：先问预算再讲区别",
  "content": "场景：客户嫌贵、拿别家比价时\n话术：——哥，您预算大概什么范围？我按您预算配最合适的组合，贵有贵的道理，我先给您讲讲差在哪——\n要点：先问预算能省一半拉锯；不贬低同行，只讲自己方案的价值",
  "tags": ["报价", "比价"]
}
```

或素材不足时：`{ "reject": "对话只有两轮且未涉及可提炼的销售动作" }`
